# PIF403 Pengantar Kecerdasan Buatan

Bahan ajar dan latihan mata kuliah **PIF403 Pengantar Kecerdasan Buatan**, Program Studi Informatika, Universitas Adzkia (semester 2026-1). Pengampu: Muhammad Thoriq.

Repositori ini berisi slide, tugas atau lembar kerja, dan notebook Google Colab per pertemuan. Pertemuan 1 dan 2 tidak disertakan, pertemuan 8 adalah UTS, dan pertemuan 12 sampai 16 digabung menjadi projek akhir.

## Cara memakai notebook

1. Klik tombol **Open in Colab** pada pertemuan yang dikerjakan.
2. Unduh berkas data yang dibutuhkan dari folder [`data/`](data/) ke komputer Anda. Data **tidak** tertanam di notebook.
3. Jalankan sel pengunggah berkas di notebook, lalu pilih berkas CSV tersebut.
4. Kerjakan sel latihan bertanda `TODO`. Simpan hasilnya ke Drive Anda lewat *File → Save a copy in Drive*, jangan mengubah notebook di repositori ini.
